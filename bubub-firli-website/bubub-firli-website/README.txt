WEBSITE UNTUK BUBUB FIRLI ♡
=============================

CARA MEMBUKA DI VS CODE
1. Extract file ZIP ini.
2. Buka VS Code.
3. Pilih File > Open Folder.
4. Pilih folder "bubub-firli-website".
5. Buka file index.html.
6. Klik kanan > Open with Live Server (jika ekstensi Live Server sudah dipasang).
   Kalau belum ada, klik dua kali index.html dari File Explorer untuk melihatnya di browser.

CARA MEMASUKKAN FOTO KALIAN
1. Siapkan 3 foto yang ingin ditampilkan.
2. Masukkan ke folder assets.
3. Ubah nama file menjadi:
   - foto1.jpg
   - foto2.jpg
   - foto3.jpg
4. Jika fotomu format PNG, ubah juga nama file di index.html dari .jpg menjadi .png.
5. Refresh browser.

CARA MENGUBAH ISI SURAT
1. Buka index.html.
2. Cari bagian <article class="letter-card" id="letterCard">.
3. Edit paragraf di dalamnya sesuai kata-katamu sendiri.
4. Simpan dengan Ctrl + S lalu refresh browser.

CARA ONLINE GRATIS DENGAN GITHUB PAGES
1. Buat akun atau login di https://github.com
2. Klik tombol + > New repository.
3. Isi nama repository: bubub-firli
4. Pilih Public, lalu klik Create repository.
5. Di halaman repository, pilih Add file > Upload files.
6. Upload SEMUA ISI folder website (index.html, style.css, script.js, README.txt, dan folder assets).
   Pastikan index.html berada langsung di bagian utama repository, bukan di dalam folder tambahan.
7. Klik Commit changes.
8. Buka Settings > Pages.
9. Pada bagian Build and deployment, pilih Deploy from a branch.
10. Branch: main, folder: / (root), lalu klik Save.
11. Tunggu beberapa menit. Link website akan muncul di halaman GitHub Pages.

CATATAN
- Hosting GitHub Pages gratis untuk repository publik.
- Jangan unggah foto atau informasi pribadi yang tidak ingin dilihat publik.
- Website ini statis, jadi tidak membutuhkan database atau backend.
- Musik belum ditambahkan agar website tetap ringan. Bisa ditambahkan nanti jika diinginkan.
